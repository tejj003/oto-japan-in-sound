# Contributing

Run `npm run dev` and `npm run check` before proposing a change. The project uses native browser APIs and has no build dependencies.

For visual or audio changes, check all three scenes on desktop and mobile. Use an actual uploaded audio file as well as the demo track. Confirm that beats drive the water, fish retain a natural swimming pace, quiet passages do not create new beat wakes, and moon movement stays subtle.

Verify PNG export and a short video recording with audio in a supported browser. Respect reduced-motion preferences and keep keyboard focus visible.

Keep generated recordings, personal audio files, credentials and hosting-specific configuration out of commits. Retain the bundled font licenses when changing assets.
